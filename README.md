# Adaptive Embodied AI

## A Human-Centered AI Research Prototype for Adaptive Embodied Interaction

## Overview

This project investigates how AI systems can adapt to individual human movement patterns instead of requiring users to conform to predefined interaction rules.

## Research Question

How can interactive AI systems adapt to individual movement patterns to enable more intuitive and transparent embodied interaction?
